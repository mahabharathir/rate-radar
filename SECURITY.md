# Security Policy

## Static Frontend Architecture

Rate Radar is a static client-side application. The frontend:
- Does not collect or store personal user data
- Does not run server-side authentication
- Does not process payments or credit card numbers
- Does not connect to private backend databases

## Reporting a Vulnerability

If you discover a security concern regarding client-side data handling, dependency integrity, or content security:

1. Please open a private security advisory on GitHub or email the maintainers at security@rateradar.org.
2. Provide details of the issue and steps to reproduce.
3. We will review and address the report promptly.
